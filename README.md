# Adereso Desk

Landing de Adereso Desk, publicada en GitHub Pages.

Esta es la versión aprobada: los cuatro mockups muestran sus portadas mientras
las animaciones se preparan anticipadamente. Sólo se reproduce la etapa visible;
las demás permanecen pausadas y vuelven al inicio al entrar nuevamente.

## Archivos

- `index.html`: landing principal.
- `hero-tabs.css`: tabs del hero en light y tablero de monitoreo en dark.
- `inbox-fit.js`: ajuste del contenido de la bandeja a su altura fija, sin scroll interno.
- `hero-viewport.js`: escala proporcional del hero para ver el mockup y sus tabs juntos en el viewport.
- `mockups/`: cuatro animaciones HTML con control de reproducción.
- `posters/`: portadas estáticas de los mockups.

## Publicación

GitHub Pages publica directamente la raíz de la rama `main`.
No requiere instalación ni compilación. Los cambios enviados a esa rama
actualizan el sitio: https://paraya-adere.github.io/desk/
